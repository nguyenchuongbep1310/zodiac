# AskNova Astrology Website Design Prompt

## Project Overview
Design a modern, elegant astrology website similar to AskNova (asknovaastrology.com) that serves as a birth chart calculator and astrology learning platform. The design should balance sophistication with accessibility, making astrology approachable for both beginners and experienced practitioners.

---

## Visual Design System

### Color Palette
- **Primary Background**: Soft beige/cream (#F5F3F0 or similar warm neutral)
- **Accent Colors**:
  - Burgundy/Maroon: #8B6B66 or #6B4C47 (for boxes, buttons, accents)
  - Deep Blue/Purple: #4A5568 or #5B5E7E (for secondary accents)
  - Teal/Forest Green: #3D6B5D or #4A7B6F (for tertiary accents)
  - Warm Gold/Tan: #C9A877 (for highlights and secondary text)
- **Text Colors**:
  - Dark Brown/Charcoal: #3C3C3C for main text
  - Medium Gray: #7A7A7A for secondary text
- **Dark Sections**: Deep brown/burgundy (#5C4A47) for footer and CTA sections
- **White**: Pure white (#FFFFFF) for content areas and cards

### Typography
- **Headlines**: Serif font (elegant, sophisticated - similar to "Playfair Display" or "Crimson Text")
  - Hero title: Extra large, bold weight
  - Section titles: Large, elegant
- **Body Text**: Clean sans-serif (similar to "Inter", "Montserrat", or "Open Sans")
  - Regular weight for body content
  - Light weight for secondary text
- **Accent Text**: Italic serif for taglines and descriptive text

### Design Elements
- **Rounded Corners**: Subtle border-radius (8-12px) on cards, buttons, form inputs
- **Spacing**: Generous whitespace (40-80px vertical sections)
- **Shadows**: Subtle, soft shadows on cards for depth
- **Borders**: Minimal use, only when needed for form inputs
- **Hover Effects**: Smooth transitions, color changes, slight scale transforms

## Page Structure

### 1. Navigation Bar (Fixed/Sticky)
- **Logo**: "AskNova" (or similar brand name) in italic serif
- **Navigation Items** (responsive):
  - Daily Horoscope
  - Charts (dropdown menu)
  - Compatibility (dropdown)
  - Tools (dropdown)
  - Learn (dropdown)
- **Right Side**: Sign In button (outlined or filled style)
- **Mobile**: Hamburger menu icon
- **Design**: White/cream background with dark text, clean and minimal

### 2. Hero Section
- **Layout**: Left-right split or center-aligned
- **Left Side** (or top on mobile):
  - Main Heading: "Create Your Birth Chart" (serif, large)
  - Subheading: "Cast" or descriptive text (smaller, secondary color)
  - **Form with 3 fields**:
    1. Birth Date (date picker input)
    2. Birth Time (time picker with "Unknown birth time" checkbox)
    3. Birth Location (search input with dropdown, option to enter coordinates manually)
  - **Additional**: "+ Show Extended Settings" link
  - **CTA Button**: "Create Birth Chart" (rounded, solid burgundy/teal, full width)
  
- **Right Side** (or bottom on mobile):
  - Interactive birth chart wheel visualization/preview
  - Clean, detailed astrology chart wheel with planets and houses
  - Multiple colored lines showing aspects

- **Background**: Soft gradient or solid warm neutral color

### 3. Features Section
- **Title**: "Features" (or none, integrated into layout)
- **Layout**: Grid or carousel of 4 clickable feature cards/buttons
- **Cards Include**:
  1. "Your Birth Chart. All Layers. One Place."
  2. "Mutual Receptions, Surfaced"
  3. "House System & Orbs Toggle"
  4. "Click Any Planet"
- **Each Card**: Icon/visual + heading + brief description
- **Interaction**: Cards are clickable buttons showing more details or linking to features
- **Background**: Light neutral or white
- **Positioning**: Featured area below hero, full-width or contained

### 4. Learn Astrology Section
- **Title**: "Learn Astrology" (large serif heading)
- **Tagline**: "Clarity. No Fluff." (smaller, italic, secondary color)
- **Layout**: 3-column grid (responsive to 1-2 columns on smaller screens)
- **Article Cards**:
  - **Featured Image**: Beautiful, artistic astrology-themed illustrations
  - **Article Title**: "Explaining the Lot (or Part) of Fortune", "Aries Rising: The Pioneer Ascendant", "Morning Star and Evening Star: Solar Orientation in the Birth Chart"
  - **Description**: Brief excerpt (2-3 lines)
  - **Link**: Subtle link style or card click interaction
- **Card Style**: Bordered or shadow, with image on top, text below
- **Background**: White or light cream

### 5. "Accurate. Simple. Capable." Section
- **Title**: Large, centered serif text reading "Accurate. Simple. Capable."
- **Layout**: Central title with 4 colored boxes positioned around it
- **Feature Boxes** (each distinct color):
  1. **Burgundy Box**: "Made for All Levels" + description
  2. **Gray Box**: "Simple Surface, Deep Core" + description
  3. **Blue/Purple Box**: "Swiss Ephemeris" + description

- **Background**: Light cream/beige
- **Typography**: Bold title in serif, body text in sans-serif

### 6. FAQ Section
- **Title**: "A Couple of Things" (serif, large)
- **Layout**: Single-column list of expandable FAQ items

  1. "What is a birth chart?"

- **Background**: White or light cream

## Interactions & Animations

- **Smooth Scrolling**: Entire page scrolls smoothly
- **Hover Effects**: 
  - Links slightly change color or underline
  - Cards have subtle lift/shadow effect
  - Buttons change shade or opacity on hover
- **Form Inputs**: Focus states with color change or border highlight
- **FAQ Expansion**: Smooth accordion-style animation
- **Navigation**: Sticky behavior, stays visible on scroll
- **Transitions**: All color/opacity changes use 200-300ms transitions

---

## Responsive Design

- **Desktop**: Full multi-column layouts, all features visible
- **Tablet**: Adjusted grid (2 columns for article cards, reorganized feature boxes)
- **Mobile**: 
  - Single column layout
  - Hero form and chart stacked vertically
  - Feature cards in single column or carousel
  - Hamburger menu for navigation
  - Full-width buttons and inputs
  - Adjusted typography sizes for readability

## Design Principles

1. **Elegance meets Accessibility**: Sophisticated design that doesn't intimidate beginners
2. **Clear Information Hierarchy**: Important elements stand out naturally
3. **Generous Spacing**: Lots of whitespace for breathing room
4. **Subtle Animations**: Smooth, purposeful transitions
5. **Consistent Branding**: Cohesive color, typography, and spacing throughout
6. **Responsive First**: Works beautifully on all devices
7. **Fast Loading**: Optimized images and efficient code
8. **Trust & Credibility**: Professional design signals expertise and reliability

## Browser Support

## Performance Considerations
- Lazy load article images
- Optimize chart SVG/canvas rendering
- Minimize CSS/JS bundles
- Use web fonts efficiently
- Cache static assets
- Optimize form inputs for mobile keyboards

---

## Accessibility
- Semantic HTML structure
- ARIA labels for interactive elements
- Keyboard navigation support
- Color contrast ratios meet WCAG standards
- Alt text for images
- Focus visible states for keyboard users
